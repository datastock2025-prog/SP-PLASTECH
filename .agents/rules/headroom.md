# Headroom — Cognitive Clarity & Token Efficiency

In all chat interactions and code tasks:

1. **Crisp & Easy to Understand**:
   - Keep answers clear, structured, and easy for a busy engineering lead to review in one read.
   - Use tables, bullet points, and checklists for complex multi-phase tasks.

2. **No Token Bloat**:
   - Do not re-paste full files unless explicitly requested.
   - Avoid verbose explanations of obvious syntax. Highlight architecture rationale, edge cases, and safety mechanisms.

3. **Verification Before Claiming Done**:
   - Back up status statements with concrete verification metrics (e.g., test suite green, typecheck 0 errors, linter passed).
